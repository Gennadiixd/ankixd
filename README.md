# Карточки

Сайт для повторения карточек: FSRS, колоды, папки и теги. База SQLite лежит в `data/ankixd.sqlite`.

Локально:

```bash
npm install
npm run dev
```

Вход по логину и паролю. У каждого пользователя свои колоды. Пароль хранится как scrypt-хеш с солью, сессия в базе не имеет срока.

```bash
npm ci
npm run build
npm start
```

`npm start` слушает `127.0.0.1:3000`. Перед ним поставьте nginx с HTTPS и `proxy_pass http://127.0.0.1:3000`. Пробросьте реальный адрес клиента: `X-Real-IP` и `X-Forwarded-For`. По ним считаются неудачные входы и регистрации. Каталог `data/` не удаляйте при обновлении: в нём вся история повторений.

## Требования

Это сайт, не Telegram. Вход по логину и паролю, колоды принадлежат пользователю. Интерфейс русский, сначала для телефона. Геймификации нет.

Повторение идёт по FSRS-7: желаемое удержание 0.9, без случайного разброса интервалов. Кнопки две — «Не вспомнил» и «Вспомнил». На них виден следующий интервал. Расписание принадлежит карточке. Правка текста карточку не сбрасывает. Последний ответ можно отменить. Дневного лимита новых карточек нет.

В сессию попадают карточки, срок которых уже наступил. Сначала короткие шаги, затем обычные повторения от более раннего срока, затем новые в порядке добавления. Ответ с интервалом до минуты возвращает карточку в конец очереди. Интервал до 15 минут оставляет её в этой сессии и показывает, когда срок наступит. Более длинный интервал уходит из сессии. Сессию можно закончить досрочно: уже данные ответы сохраняются.

Колоды группируются папками в один уровень. Папка только группирует, её можно свернуть. Колоду можно создать, переименовать, перенести, удалить и править её поля из меню с тремя точками. Повторение всей колоды запускается кнопкой play в списке, без входа в колоду.

Повторять можно всю колоду или выбранные теги внутри одной колоды. Несколько тегов объединяются через «или». У карточки есть редактор. HTML в полях очищается. Импорт XML всегда создаёт новую колоду и переносит поля, карточки и теги.
